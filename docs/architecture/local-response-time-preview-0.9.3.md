# Локальный прогноз времени ответа ИИ-помощника BPM 0.9.3

`BPM093-M13-05` добавляет предварительный диапазон времени для уже принятого запроса
ИИ-помощника. Он не является SLA, не влияет на приоритет, отмену или длину ответа.

До запуска фоновой генерации `ConversationStreamController` получает от локального runtime
диапазон в целых секундах. В ответе `POST /api/documentation-assistant/chat` находятся только
`minimum_seconds` и `maximum_seconds`. Браузер не получает измерения, идентификатор оборудования,
промпт, доказательства, пути, ответ модели либо внутреннюю скорость генерации. Для каждой из шести
локалей браузер показывает обе границы как минуты и секунды; например, «от 2 минут 15 секунд до
6 минут 40 секунд».

Оценка использует только текущие локальные факты: доступные для worker CPU-потоки, фиксированные
идентификаторы проверенной модели Qwen3 Q8_0 и llama.cpp runtime, cold/warm состояние, длины
вопроса и сохранённого контекста, бюджет выбранного пакета доказательств, предсказанный диапазон
токенов ответа и среднюю скорость последних четырёх локальных генераций. Для cold или неизвестного
состояния верхняя граница расширяется. Новый запуск, установка либо изменение runtime начинают
калибровку заново. Эти сведения хранятся только в памяти процесса, не записываются, не отправляются
в телеметрию и не требуют сети.

Технические лимиты остаются явными: максимум 512 токенов как ресурсный предел worker, 900 секунд
на ответ, 1 200 секунд на полный запрос, 4 096 токенов контекста и ограничение RSS. Инструкция
модели больше не содержит ограничения по словам или абзацам: она должна дать весь подтверждённый
ответ в пределах этих технических границ.
