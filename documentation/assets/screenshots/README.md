# Localized Screenshot Sources

The six locale directories contain reviewed, publishable BPM UI screenshots. Captures use synthetic
fixtures and may not contain credentials, real users, customer data, private hosts, local paths, or
unapproved third-party branding.

The same locale-independent asset ID and filename stem is used in every locale. A capture becomes a
source asset only after visual, locale, privacy, provenance, and accessibility review. Transient
browser captures and diffs belong under ignored `documentation/reports/`, not here.
